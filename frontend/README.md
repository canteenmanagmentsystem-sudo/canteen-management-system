# Canteen Management Frontend

This frontend covers the Dashboard and Reports module for the Canteen Management System.

## Backend expected

Backend:
http://localhost:5000

API:
http://localhost:5000/api

Create `.env`:

VITE_API_BASE_URL=http://localhost:5000/api

## Install

npm install

## Run

npm run dev

## Build

npm run build

## Login

The login screen defaults to:

username: admin
password: ChangeMe@123

Change the password on the backend before production.

## Reports included

- Dashboard
- Sales
- Sales by Food Item
- Sales by Department
- Purchases
- Collections
- Outstanding
- Expenses
- Stock
- Stock Movements
- Wastage

## Language

English and Hindi are built in and saved in localStorage.

## Important

This is the frontend for the Dashboard/Reports layer. It is designed to connect to the backend report APIs already implemented in the project.
